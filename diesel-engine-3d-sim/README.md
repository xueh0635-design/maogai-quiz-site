# 四冲程柴油机 3D 交互仿真

此目录用于保存与参考视频 `video_20260814_015807.mp4` 对照迭代的柴油机 3D 仿真版本。

- `index.html`：始终指向最新可运行版本
- `versions/`：历史版本入口
- `payloads/`：压缩后的版本源码载荷，由版本入口自动解压运行
- `logs/`：每轮迭代复盘、评分和下一轮计划

当前最新稳定版本：**V15 Crankshaft Geometry Fix**。

V15 已精确移除错误的贯穿式 `Main Crankshaft` 大圆柱，并改为 5 个分离主轴颈 + 既有曲柄臂/连杆颈/配重组合；V14 及更早历史入口继续保留。

> 目标：在可验证的视觉、机械运动、系统交互、P–V 图、爆炸拆解和移动端体验上达到并超过参考视频。未完成全部验收前不会标记为“已超过参考”。
