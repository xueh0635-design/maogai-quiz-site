# 四冲程柴油机 3D 交互仿真

此目录用于保存与参考视频 `video_20260814_015807.mp4` 对照迭代的柴油机 3D 仿真版本。

- `index.html`：始终指向最新稳定版本
- `versions/`：历史版本入口
- `payloads/`：压缩后的版本源码载荷，由版本入口自动解压运行
- `logs/`：每轮迭代复盘、评分和下一轮计划

当前最新版本：**V17 CAD-Like Cutaway**。

V17 的重点是把视觉从“透明大方盒 + 粗圆柱示意件”推进到更可信的工业数字样机：默认实体铸件、开放式剖视骨架、分段曲轴主轴颈、细轴芯 + 桃形凸轮、圆角壳体/曲柄臂、加强筋与重新标定的 PBR 光照。

> 目标：在可验证的视觉、机械运动、系统交互、P–V 图、爆炸拆解和移动端体验上达到并超过参考视频。未完成全部验收前不会标记为“已超过参考”。
