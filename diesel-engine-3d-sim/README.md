# 四冲程柴油机 3D 交互仿真

此目录用于保存与参考视频 `video_20260814_015807.mp4` 对照迭代的柴油机 3D 仿真版本。

- `index.html`：始终指向最新可运行版本
- `versions/`：历史版本入口
- `payloads/`：压缩后的版本源码载荷，由版本入口自动解压运行
- `logs/`：每轮迭代复盘、评分和下一轮计划

当前最新版本：**V16 Camshaft Geometry Rebuild**。

V16 针对用户 iPhone 实机截图重新定位了画面中央粗横轴：该部件实际属于 `Camshaft Assembly`，而不是 V15 误判的下部 `Main Crankshaft`。V16 改为在 payload 解压后、源码执行前直接重写凸轮轴和曲轴几何，避免此前外部热修无法访问函数局部 `scene` 的作用域问题。

> 目标：在可验证的视觉、机械运动、系统交互、P–V 图、爆炸拆解和移动端体验上达到并超过参考视频。未完成全部验收前不会标记为“已超过参考”。
