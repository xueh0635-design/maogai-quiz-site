# 四冲程柴油机 3D 仿真 V41 复盘 / 验收记录

## 本轮结论

当前最新稳定版推进到 **V41 Integrated Mechanical Runtime**。本轮没有报告“最终完成”或“已超过基准”。首要基准仍为用户上传的 `video_20260814_015807.mp4`；本轮能重新利用的是此前已保存的抽帧/ffprobe 复核记录，而不是原 MP4 字节的重新逐帧读取。

## 基准证据边界

此前保存记录确认：`video_20260814_015807.mp4` 约 50.917 s、2400×1080、24 FPS；关键证据包括透明剖视 + 信息卡、系统拆解 + 散热器、裸机内部机构、深度爆炸 + 信息卡，以及右侧持续实时参数与 P–V 图。另有保存记录确认基准强调 1-3-4-2 / 720°、独立系统显隐、细化配气、动态参数和大量附件/管路。

对 BV1kLgs6vETz / o4UzlBJ 的公开搜索本轮仍未可靠解析到指定视频页面，因此没有使用其它柴油机视频替代首要基准。

## V40 复盘定位出的主要问题

1. V40 仍通过 `V40 -> V35 -> V34 -> V32 -> V25` 叠加运行层，虽已比早期更稳定，但运行链仍偏深。
2. V35 的工业复杂度层和 V40 的流体/QA 位于不同包装层，导致维护和状态同步逻辑分散。
3. 与目标图/基准相比，主轴承腹板、横向主轴承螺栓、DOHC 轴承桥、共轨安装与回油、排气法兰/螺柱、附件皮带驱动、起动机、涡轮供回油和服务件层级仍需要继续强化。

## V41 实际改进

### 1. 降低运行链深度

V41 不再继承 V35/V40，而是直接从 V34 动态层进入，再在同一 V41 层整合工业总成、服务管路、连续流体和运行 QA。目标链路变为约：

`V41 -> V34 -> V32 -> V25`

自动 QA 要求 `iframeDepth <= 4`。

### 2. 曲轴箱 / 主轴承结构

新增或强化：
- 5 道曲轴箱主腹板
- 5 组主轴承座 / 主轴承半环
- 横向主轴承盖贯穿螺栓及垫圈
- 四缸缸筒加强肋
- Deck 支撑肋
- 四缸 Fire Ring
- 高对比红色机械加工剖切边

### 3. DOHC / 顶部服务面

新增：
- 10 个 DOHC 凸轮轴承桥
- 凸轮轴瓦视觉环
- 轴承桥螺栓
- 四套喷油器压板 / 压板螺栓
- 四个喷油器电连接器
- 主线束 / 分支线束 / 线束支架

V34 的 16 个动态气门、双凸轮轴半速同步、四缸独立喷油 / 燃烧 / 进排气继续保留。

### 4. 共轨燃油硬件

新增/整合：
- 共轨本体
- 4 个共轨安装脚
- 4 个高压接头六角螺母
- 4 根独立刚性高压喷油管
- 4 路喷油器回油软管和三通
- 回油总管
- 轨压传感器 / 限压阀 / 传感器线束

### 5. 排气 / 涡轮连接层级

新增：
- 四缸实体排气法兰
- 密封垫环
- 双螺柱 + 螺母
- 支路焊环
- 涡轮入口 V-band
- Wastegate 执行器与连杆

### 6. 前端附件驱动

新增/强化：
- 双层曲轴扭振减振器
- 水泵带轮
- 惰轮
- 自动张紧器
- 发电机壳体 / 带轮 / 18 条散热肋
- 闭合多楔带路径
- 起动机 / 起动齿轮 / 电磁开关

### 7. 润滑 / 冷却服务总成

新增/整合：
- 全流式机油滤清器 + 滤座
- 进出口接头
- 主油进回油硬管
- 涡轮压力供油管 + Banjo
- 涡轮重力回油管
- 缸盖冷却跨接管 + 卡箍

### 8. 连续流体和系统显隐

V41 在同一层整合：
- 冷却液连续流
- 主油道润滑油连续流
- 涡轮供油连续流
- 四缸共轨高压燃油连续流

系统显隐同时读取“系统聚焦”和复选框；深爆炸状态下流体逐步淡出并隐藏，避免粒子悬空。

### 9. Hover 信息卡

V41 本轮新增的非粒子工业件全部加入独立 Raycaster 和工程信息卡元数据；保留基础运行时已有 Hover。

## 自动运行验收

V41 内置 `window.__v41Debug`，检查：
- V34 基础动态层是否通过
- WebGL / Canvas
- 工业层 Mesh 密度
- 全场景 Mesh 密度
- iframe 深度 <= 4
- P–V Canvas 是否有真实像素变化
- 三类连续流体粒子数量
- 剖视 / 爆炸 / 播放 / 四预设视角控件
- 90° / 270° / 450° / 630° 四冲程相位
- 90° 进气门和 630° 排气门开启
- 爆炸时流体隐藏同步
- 侧视 / 正视相机变化
- OrbitControls 模拟拖拽
- 动画帧推进
- QA 后曲轴角 / 播放状态 / 爆炸度恢复

本轮新 V41 JavaScript 在写入 GitHub 前使用 `node --check` 做了语法检查，结果通过。

## 仍未验证 / 阻断项

1. 本轮没有重新获得 `video_20260814_015807.mp4` 原始字节，不能做新的逐帧差异量化。
2. 当前工具环境没有独立真实浏览器截图级 WebGL 回归证据；`__v41Debug` 属于页面内部自动回归，不能替代人工/独立 Chromium 视觉验收。
3. 真实 FPS、移动端 Safari/GPU、长时间运行稳定性仍未验证。
4. 所以不得报告“全部关键验收已达到/超过基准”或“最终完成”。
