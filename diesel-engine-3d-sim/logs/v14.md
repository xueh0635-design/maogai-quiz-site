# V14 复盘：Mechanical Coherence / 机械一致性修正

本轮继续以用户上传的 `video_20260814_015807.mp4` 为首要基准。历史抽帧记录显示，参考视频重点包含：四缸 1-3-4-2、透明剖视、系统拆解/深度爆炸、裸机内部机构、信息卡、实时参数和 P–V 图。V4 以后项目已经具备摇臂轴、摇臂、推杆、挺柱、滚轮、真实凸轮轮廓以及每缸独立喷油/进排气流动，因此本轮优先修复最新版本出现的“机械架构互相冲突”问题，而不是继续叠加另一套配气机构。

## 本轮发现的阻断性问题

1. V13 为修复用户截图中部的异常粗横轴，又额外叠加了一套 `V13_REFERENCE_GEOMETRY` / DOHC 几何层。
2. 该做法与项目既有的摇臂轴 + 推杆 + 挺柱配气链不一致，且会在原模型上重复添加缸盖、双凸轮轴、燃油轨和歧管，存在重叠、遮挡和新的几何冲突风险。
3. V13 的异常横轴删除规则使用较宽的包围盒筛选，有误伤合法长圆柱零件的风险。

## V14 已直接实施

- 默认入口升级到 V14，继续复用 V12 的完整实体 payload、运动、流体、图表与交互功能。
- **取消默认版本中的 V13 additive DOHC overlay**，不再在既有 OHV/推杆式配气模型上叠加第二套配气架构。
- V13 作为历史版本独立保存在 `versions/v13.html`，没有删除历史版本。
- 中部异常粗横轴修复改为更窄的缺陷特征：
  - 必须是 CylinderGeometry；
  - 世界包围盒 X 跨度 > 320；
  - Y/Z 截面均 < 120；
  - 中心 Y 位于 175–325；
  - |Z| < 95；
  - 原始圆柱高度 > 280 且半径 >= 18。
- 仅隐藏与该错误轴同轴、近邻的小型圆盘/套筒件，避免留下悬空环件。
- 不触碰下部曲轴、顶部燃油轨、进排气歧管和原有配气机构。
- 如果上一版本留下过高曝光，则 V14 只做上限收敛到 1.06；不再增加额外灯光。
- 手机端继续保持不大于 34° FOV 的近镜头策略。

## 代码/部署验证

- `index.html` 现在默认加载 V14，`?version=v12` 保留兼容模式，`?version=v13` 跳转到独立历史版本。
- V14 不再注入 `V13_REFERENCE_GEOMETRY`，避免重复配气/缸盖/歧管。
- V14 的异常横轴删除规则相比 V13 明显收窄，降低误删合法长圆柱的风险。
- 历史 V13 已从原先的简单重定向改为独立可加载页面，确保 V14 更新后仍能访问 V13 行为。
- 本轮只修改 `diesel-engine-3d-sim/` 子目录。

## 尚未验证 / 不能宣称完成

1. 当前运行环境仍无法可靠做真实 iPhone Safari / 桌面 Chrome 的 WebGL 同视角截图回归，因此不能确认异常粗横轴在所有相机角度都已完全消失，也不能对视觉效果做“超过参考视频”的结论。
2. 首要基准视频虽然已有历史抽帧与评分记录，但本轮未重新读取视频原始字节做逐帧新对比。
3. CAD 级外形、法兰/管接头/紧固件/壳体曲面仍是与参考视频的主要差距。
4. 真实持续 FPS、内存占用、iOS WebGL 稳定性仍缺实机证据。

## 当前结论

V14 修掉了最新版本最危险的机械一致性问题：不再用第二套 DOHC 几何覆盖已有推杆式配气系统，并将用户指出的中部异常粗横轴热修范围收窄。当前仍不满足“全部关键验收项均有证据达到或超过参考”的完成条件，因此项目继续保持迭代状态。
