# 四冲程柴油机 3D 仿真 — V22 复盘与验收记录

## 本轮复盘结论

V21 已恢复燃油、润滑、冷却、进排气五类动态流动，但最新代码仍与用户给出的参考截图/视频存在明显差距。主要短板不再是“有没有功能”，而是发动机外围工业附件密度、法兰/紧固件/冷却与EGR支路、流体显示方式和整体机械可信度仍偏程序化教学模型。

## 逐项检查

- 结构完整度：四缸本体、曲柄连杆、DOHC 16V、共轨、进排气、涡轮、正时、发电机、油滤已具备；V22 新增飞轮壳、起动机、水泵、节温器、高压燃油泵、EGR 冷却器、机油冷却器、传感器/线束及更多附件管路。
- 拆解层级：V20/V21 已按 motion / valve / fuel / gas / details 分组爆炸；V22 新增 hardware / auxiliary / gas 三组并随爆炸量分层位移。
- 曲柄连杆与配气相位：继续采用四缸 720° 循环和 1-3-4-2 相位逻辑；双凸轮按曲轴 1/2 转速运行，16 气门使用原 valveLift 逻辑。
- 燃油/润滑/冷却流动：V21 已恢复五类流动；V22 将“纯球形粒子串”改为半透明连续流管 + 更小的移动示踪粒子，降低玩具感。
- PBR 材质：继续使用铸铁/铝合金/机加工钢/黄铜/橡胶等分层 MeshPhysicalMaterial；V22 增加铸铁、机加工钢、附件铝壳和暗色壳体层次，并重新压低曝光避免金属过曝。
- 剖视/爆炸：保留前盖隐藏、红色剖切边、冷却水套与 section plane；新增附件跟随爆炸位移。
- 多视角：沿用 front / side / top / iso 与 OrbitControls。
- 悬浮信息卡：继续保留 raycaster hover；V22 新增飞轮壳、高压燃油泵、冷却水泵信息卡。
- 实时状态与热力学：沿用 RPM、负荷、温度、压力、四冲程状态、实时 P–V 与性能参数。
- 交互体验：默认仍可运行、暂停、步进、重置、剖视、爆炸、系统显隐、视角切换、双击聚焦。

## V22 直接实施的高优先级改进

1. 新增飞轮壳与 12 点连接法兰、起动机/电磁开关，使右端总成不再只是一只孤立飞轮。
2. 新增机械水泵、节温器、硬质冷却管和卡箍，补足冷却系统可见硬件。
3. 新增高压燃油泵、计量阀和共轨高压供油管，补足“共轨只有一根 rail”问题。
4. 新增 EGR 冷却器、EGR 不锈钢回路、进气混合/节气装置。
5. 新增机油冷却器与层叠冷却片、供油硬管。
6. 新增凸轮轴承盖、缸盖螺栓、油底壳螺栓、曲轴箱加强筋、喷油器线束和压力传感器，提高机械密度。
7. 给涡轮进出口增加大直径管路与 V-band / boost clamp 细节。
8. 将 V21 流动展示由明显的球形珠串升级为连续半透明流管 + 稀疏示踪粒子。
9. 桌面默认相机重新收束到发动机主体，增加冷色轮廓光并降低曝光，强调金属高光层次。

## 验证证据

- `v22-patch.js` 已通过 `node --check`，无 JavaScript 语法错误。
- V22 包装器继续从已验证的 V19 基础 payload + V20/V21 增量补丁加载，并新增 V22 补丁；运行循环包含 `updateRefEngine(dt) + updateV21(dt) + updateV22(dt)`。
- 历史版本 V21 及更早版本保留；`diesel-engine-3d-sim/index.html` 已切到 V22。
- 本轮只修改 `diesel-engine-3d-sim/` 子目录内文件。

## 未验证与剩余差距

- 当前本地无可靠外网加载 Three.js CDN，虽能静态验证 JavaScript 与 GitHub Pages 构建，但本轮仍不能把 headless Chromium 截图视为等价真实浏览器视觉证据。
- 用户给出的参考视频/截图仍具有明显更高等级的 CAD 铸造曲面、真实涡壳/歧管曲面、纹理粗糙度、阴影/AO 与高质量材质贴图；V22 仍是程序化几何，不能声称达到或超过基准。
- 移动端在宽度 <=900 px 时会把面板改为文档流并隐藏工程 callout；功能可用，但视觉不等于桌面基准截图，需要后续专门做移动端参考布局。
- 尚缺真实 OEM 级曲面、扫描/烘焙法线、环境 HDRI、接触阴影/AO、卡箍螺杆等微细节。

## 状态

V22 是本轮直接实施的下一版稳定候选，但项目尚未达到“全部关键验收项有证据达到或超过基准”的完成条件，因此继续保持未完成状态。
