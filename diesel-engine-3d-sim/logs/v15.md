# V15 复盘：Crankshaft Geometry Fix / 曲轴几何精准修复

## 为什么用户看到“没有更新”

本轮重新下载并展开了 GitHub Pages 最近一次成功部署的 `github-pages` 构建产物。部署产物中的 `diesel-engine-3d-sim/index.html` 确实已经是 V14，因此问题不是 Pages 没有发布，也不是单纯浏览器缓存。

真正原因是 V14 的热修规则定位错了对象。V14 只筛选中心 Y=175–325 的粗横向圆柱；而解压 V12 实体 payload 后确认，用户截图中最突兀的贯穿式大圆柱实际就是源码中的：

`const crankCore=cyl(22,560,...,[0,dims.crankY,0],...,'Main Crankshaft')`

其中 `dims.crankY=92`。因此 V14 的 Y 区间不可能命中它，视觉上自然与旧版本几乎一致。

## V15 已直接实施

- 不再依赖运行时包围盒猜测，直接按对象名 `Main Crankshaft` 精确定位错误件。
- 删除原半径 22、长度 560 的贯穿式实心圆柱。
- 用 5 个分离主轴颈替换，轴向位置与现有 5 个主轴承盖一致：Z = -224、-112、0、112、224。
- 主轴颈示意尺寸为 Ø48 × 34 mm，并保留两端短轴颈。
- 既有 4 组曲柄臂、连杆颈、配重和 1-3-4-2 曲柄相位逻辑保持不变。
- 信息卡同步改写，明确曲轴由“分离主轴颈 + 曲柄臂 + 连杆颈 + 配重”构成，不再把贯穿圆管称作曲轴主轴系。
- 默认入口升级到 V15；`?version=v14` 继续保留 V14 行为，V13 独立历史入口继续保留。
