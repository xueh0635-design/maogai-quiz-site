# V11 Clear View / 清晰视图专项修复

本轮针对用户在 iPhone GitHub Pages 页面中反馈的 3D 发动机“整体发灰、像隔着一层灰膜、缩小后主体几乎看不清”的问题做专项修复。

## 直接实施的修改

- 默认关闭剖视模式：进入页面先显示实体整机，不再让半透明壳体默认覆盖模型。
- 显著减弱指数雾：FogExp2 密度降低到 0.00018，并将背景固定为深蓝黑，避免远景被灰雾吞没。
- 提高 ACES 曝光至 1.38，并增加环境光、正面补光、轮廓光和低位补光，减少暗部死黑。
- 缸体、缸盖、钢件、铝件整体提亮，并对铸件加入很轻的 emissive lift，增强小屏下的轮廓辨识度。
- 手机端默认镜头更近，FOV 收紧到 34°，3D 视口从 66vh 提高到 72vh；缩小页面时主体仍保持更大占屏面积。
- 手机端默认隐藏悬浮零件标签，标签启用时改为 depthTest=true，避免标签穿透模型并遮挡主体。
- UI 面板透明度降低，顶部操作提示约 2.6 秒后自动淡出。
- 剖视透明壳的默认透明度从约 23% 降到 10%，并将可调范围限制为 4%–45%，即使重新开启剖视也不会再形成明显灰膜。
- 新增“清晰视图”按钮，默认启用；可在高对比清晰模式与较原始的展示模式之间切换。
- “复位”操作现在会同时退出剖视，并在手机端恢复到更近、更清晰的轴测镜头。

## 验证

- 本轮主脚本通过 `node --check`。
- HTML 共 73 个 DOM ID，73 个唯一 ID，无重复。
- 已确认源码中存在：默认 `cutaway=false`、高对比曝光、低雾密度、正面补光、移动端近镜头、移动端默认隐藏标签、清晰视图按钮和 10% 剖视透明度。
- GitHub Pages 默认入口已更新为 v11 清晰视图版本。

## 尚未闭环的验证

当前执行环境仍无法可靠完成真实桌面 Chrome / iPhone Safari 的 WebGL 截图级自动验收，因此本轮不声称整体视觉已超过参考视频。当前目标仅是优先解决实际用户截图中“发灰、看不清、缩小后主体消失”的可视性问题。
