# V12 复盘：移动端沉浸模型视图

本轮继续以用户上传的 `video_20260814_015807.mp4` 为首要视觉基准。基准视频中，3D 发动机始终占据主视觉区域，左右控制面板不会压缩主模型到难以辨认；此前手机端页面虽然 v11 已去灰，但 UI 仍然会让模型区域显得偏小。

## 本轮直接实施

- 新增移动端“⛶ 模型全屏”按钮：一键隐藏顶部栏、左右面板、底部 Dock、引导提示和十字标，3D 视口切换为 `100dvh`。
- 沉浸模式下自动把镜头推进到更近的轴测位置，并将 FOV 收紧至 32°，让发动机主体在小屏上保持更大的占屏比例。
- 沉浸模式自动关闭悬浮标签，避免标签覆盖零件；退出沉浸后保留正常控制界面。
- 移动端普通模式的 3D 视口由约 72vh 提升到 76vh，进一步减少“模型被 UI 挤小”的问题。
- 支持 `F` 键切换模型聚焦模式，便于桌面快速 QA。
- v11 的高曝光、低雾、实体默认视图、10% 剖视壳透明度和移动端清晰镜头继续保留。

## 静态验证

- 主脚本通过 `node --check`。
- HTML 中 74 个 DOM ID，74 个唯一 ID，无重复。
- 已确认存在：`focusViewBtn`、`body.focus3d`、`setFocus3D()`、沉浸模式 100dvh 视口、32° FOV、默认 `cutaway=false` 和低雾清晰模式。
- v12 完整实体 payload 已上传到 `diesel-engine-3d-sim/payloads/v12/`，保留 v10/v11 等历史版本。

## 当前结论

v12 在“模型发灰、缩小后主体不明显、移动端 UI 挤压主模型”三个问题上继续推进，移动端已经具备单独的沉浸模型模式。功能覆盖接近基准视频中可明确观察到的主要能力，但仍不能宣称整体视觉已经超过基准视频，因为缺少真实 iPhone Safari / 桌面 Chrome 的同视角截图和持续性能实测；0.1 mm 工程精度也仍需要具体机型 CAD/工程图才能验证。
