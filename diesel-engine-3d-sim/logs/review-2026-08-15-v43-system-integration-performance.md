# 四冲程柴油机 3D 仿真 — V43 复盘与验收记录

## 基准与证据边界
- 首要基准：用户上传 `video_20260814_015807.mp4`。
- 本轮可用的既有抽帧证据：视频约 50.917 s、2400×1080、24 FPS；13.9 s 透明剖视+信息卡；23.1 s 系统拆解+散热器；32.4 s 裸机内部机构；41.7 s 深度爆炸+信息卡；右侧持续实时参数和 P–V 图。
- 本轮没有重新取得首要 MP4 原始字节做逐帧复核，因此不得声称已达到或超过视频基准。
- BV1kLgs6vETz / o4UzlBJ 仅为补充基准；本轮未获得足够可靠的公开页面证据替代上传 MP4。

## V42 复盘定位到的主要缺陷
1. V42 新增的正时传动、进气/EGR、飞轮、冷却服务件、传感器和紧固件没有完整接入左侧“系统聚焦/系统复选框”。选择 Gas、Cooling、Motion 等单系统时，V42 CAD 层仍可能残留与当前系统无关的零件，破坏系统隔离验收。
2. V42 为提高几何密度增加了大量独立齿、螺栓和螺柱。视觉复杂度提升，但每个重复件都是独立 Mesh，增加 Draw Calls 风险，与“复杂但可流畅交互”的性能目标冲突。
3. V42 剖切边缘属于 CAD 增强层本身，关闭剖视后需要跟随隐藏，否则会出现实体外壳模式仍残留红色剖切唇边的问题。
4. V42 仍缺独立 Chromium/WebGL 屏幕截图与真实 FPS 证据；这一点本轮仍未被外部浏览器环境解决。

## V43 实际实施
### 1. 系统级 CAD 显隐整合
- 正时传动组映射到 Motion / Valve / Fuel。
- Intake/EGR 气路映射到 Gas。
- 飞轮/动力输出端映射到 Motion。
- 冷却服务件映射到 Cooling。
- 传感器和紧固件按 All/相关系统条件显隐。
- V42 实体剖切唇边与 Cutaway 状态绑定，关闭剖视立即隐藏。
- Reset / Tour / 系统按钮 / 系统复选框后均重新同步 CAD 层显隐。

### 2. 重复件 InstancedMesh 性能优化
- 保留 V42 的视觉密度，不删除齿、螺栓和螺柱。
- 对同一父组内语义相同且材料相同的重复件建立 InstancedMesh。
- 覆盖：各正时齿轮齿、飞轮齿圈齿、重复 Bolt/Stud。
- 第一版按 geometry UUID 分桶会因 V42 每个重复件各自创建 Geometry 而无法合并；本轮随即修正为按“部件名称 + 材料”分桶，并复用第一件几何，避免伪装成已完成的性能优化。

### 3. 程序化回归
V43 新增 `window.__v43Debug`，检查：
- V42 基础层是否健康；
- InstancedMesh 是否实际创建，且实例总数达到阈值；
- Gas 隔离时只有气路 CAD 组保留；
- Cooling 隔离时只有冷却 CAD 组保留；
- Motion 隔离时飞轮/动力输出端保留而气路/冷却隐藏；
- All 恢复后各系统按复选框状态恢复；
- 关闭 Cutaway 后剖切 CAD 组隐藏；
- iframe 深度记录。

## 验证与未验证项
- GitHub 文件写入后已重新读取 V43，确认内容落库。
- GitHub Pages 已由最新 index 提交触发部署；记录时构建状态仍为 `in_progress`，不视为线上已验证。
- 本轮没有取得独立 Chromium/WebGL 截图；真实拖拽、Hover 命中率、最终遮挡、实际 FPS、移动 Safari/GPU 表现仍未验证。
- 首要 MP4 本轮未重新逐帧读取，因此严禁报告“超过基准”。

## 当前结论
V43 不满足“全部关键验收项均有证据达到或超过基准且无阻断性 bug”的完成条件。相比 V42，本轮最重要的实质进展是：高复杂度 CAD 层终于纳入系统聚焦/剖视状态机，同时通过 InstancedMesh 保留复杂视觉而降低重复件 Draw Calls 风险。下一关键阻断项仍是独立真实浏览器屏幕级验收和首要 MP4 逐帧复核。
