# V13 Reference Geometry

本轮按用户提供的界面模板直接重构网页中的 Three.js 三维发动机几何，而非生成静态图片。

主要修改：
- 删除/隐藏与 DOHC 结构不相符、纵向贯穿发动机的异常长柱/长杆几何。
- 重建顶置双凸轮轴（DOHC）区域：双凸轮轴、凸轮凸起、16 气门短阀杆与弹簧。
- 增加共轨、4 个喷油器、进气总管/支管、排气总管、前端正时链轮和 Deck 加强筋。
- 重新调整曝光、雾化、补光、相机视角和移动端观察距离，让模型更接近参考模板的高对比金属剖视效果。
- 主入口升级为 V13，历史 V13 入口保存于 `versions/v13.html`。

说明：V13 仍基于 V12 动画/交互核心运行，新增结构以运行时几何修正层叠加，避免破坏现有四冲程动画、P-V 图和控制逻辑。
