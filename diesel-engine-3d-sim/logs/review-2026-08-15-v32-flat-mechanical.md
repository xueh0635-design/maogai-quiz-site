# V32 Flat Mechanical Release — 复盘与验收记录

日期：2026-08-15

## 基准与证据边界
- 首要基准：用户上传 `video_20260814_015807.mp4`。当前自动化运行未重新取得原 MP4 字节，因此本轮使用已保存的抽帧记录作为基准证据：视频约 50.917 s、2400×1080、24 FPS；关键帧覆盖透明剖视、系统拆解、裸机内部机构、深度爆炸、信息卡；右侧持续存在实时参数与 P–V 图。
- 次级基准：BV1kLgs6vETz / o4UzlBJ。由于首要基准视频未重新读取，本轮不声称已经达到或超过视频最终视觉质量。

## V31 复盘
V31 功能覆盖较完整，但最大工程缺陷是版本采用 V31→V30→V29→V28→… 的多层 iframe 继承链。该结构会增加启动延迟、状态穿透复杂度、调试困难和浏览器兼容风险，并且后续每一轮继续叠层会恶化。

## 本轮实际改进：V32
V32 不再继承 V31/V30/V29 等多层包装，而是直接以已验证的 V25 本地 Three.js 运行时为底层，仅保留 1 层 iframe，并一次性加载新的复杂机械几何层。

### 结构完整度
- 前开口半壳曲轴箱、缸盖、凸轮载体、油底壳
- 5 道主轴承座、轴瓦、轴承盖、螺栓、加强筋
- 四缸燃烧室顶面与剖切边
- 每缸 4 气门：16 个气门座、导管、气门杆、气门头、弹簧、弹簧座
- DOHC 双凸轮轴、轴承盖、凸轮桃和随动件
- 中央喷油器、喷嘴和压板
- 共轨、高压泵、4 根刚性高压管、回油支路、轨压传感器
- 4 根独立进气支路、4 根独立排气支路、脉冲汇流管
- 涡轮压气机/涡轮壳、轴、13 片可见叶片、V-band、废气旁通执行器
- 全流式机油滤清器、刚性进回油管、涡轮供回油管、冷却液跨接管
- 曲轴/双凸轮正时链轮、惰轮、张紧轮、74 个可见链滚子、液压张紧器

### 拆解层级
新增几何层按顶部配气、燃油、进排气、服务管路、正时、半壳 6 组拆解，并绑定原爆炸度滑块；基础 V25 的部件爆炸机制仍保留。

### 曲柄连杆与配气相位
V32 直接使用 V25 已验证的四缸曲柄连杆和 720°/1-3-4-2 相位运行时；新增 DOHC/正时几何是结构强化层。注意：新增 V32 的凸轮/正时链几何当前主要用于结构可读性，不是独立重新求解的动力学模型，因此“几何级 2:1 正时动画完全一致”仍需浏览器级验证。

### 流动与热力学
V25 的燃油/润滑/冷却/进排气粒子流、压力温度状态、四缸燃烧/喷油效果和 P–V 图继续作为底层运行时；V32 增加真实管路/气道几何，不改变原热力学模型。

### PBR 材质
V32 新增件使用 MeshPhysicalMaterial / MeshStandardMaterial，区分铸铁、暗钢、机加工钢、铝合金、黄铜、青铜、排气耐热铁、橡胶和滤清器涂层；继续继承 V25 Studio PBR 环境反射、ACES tone mapping、软阴影和接触阴影。

### 剖视 / 爆炸 / 多视角
默认自动进入正面复杂剖视，外壳遮挡件被隐藏并替换为前开口半壳与红色剖切边。原 front/side/top/iso 多视角仍保留。V32 新增几何绑定原爆炸滑块。

### 悬浮信息卡
V32 对燃烧室、共轨、轨压传感器、冷却跨接管、液压链张紧器等新增关键件增加独立 Raycaster 与原有信息卡字段映射。

### 实时状态 / P–V / 性能
继续继承 V25 的 RPM、负荷、压力、温度、冷却液温度、机油压力、增压压力、性能参数、四缸相位和实时 P–V 图。

## 验证
- V32 外层脚本已经单独抽取并执行 `node --check`：通过，无 JavaScript 语法错误。
- GitHub vendor 目录确认 Three.js r128 与 OrbitControls r128 均存在；V32 直接加载 `v25-direct.html`，避免 V31 的深层 iframe 链。
- V32 内置 `window.__v32Debug` 运行自检，检查 THREE、canvas、P–V、剖视按钮、爆炸按钮以及新增网格数量，并显示 runtime health badge。
- GitHub Pages 针对 V32 稳定入口提交的部署工作流已被触发；记录时状态仍为 `in_progress`，因此本轮不能把“线上 Pages 已成功部署”记为完成证据。
- 本轮没有取得可执行 Chromium 的真实 WebGL 截图/交互回归证据，所以拖拽、爆炸、Hover、P–V 的最终屏幕级表现仍标记为未验证。

## 逐项验收结论
- 结构完整度：显著提升，但仍未证明达到参考视频 CAD 级复杂度。

- 燃油/润滑/冷却/进排气流动：底层覆盖，新增真实通道几何。
- PBR：覆盖。
- 剖视/爆炸：覆盖，V32 默认剖视进一步增强；屏幕级待验证。
- 多视角：覆盖。
- Hover 信息卡：基础 + V32 新增关键件覆盖；屏幕级待验证。
- 实时状态：覆盖。
- 压力/温度/P–V：覆盖。
- 性能参数：覆盖。
- 交互体验：V32 最大改进是 iframe 深度从多层降到 1 层；真实浏览器流畅度仍需验证。

## 当前结论
V32 不是最终完成版。最重要的阻断项是：尚未获得 V32 的真实 Chromium/WebGL 运行截图与交互回归，同时本轮未重新读取首要基准 MP4，因此不能声称已经达到或超过参考视频。
