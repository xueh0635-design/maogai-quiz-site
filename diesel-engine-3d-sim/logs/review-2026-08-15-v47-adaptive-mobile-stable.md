# V47 复盘：Adaptive Mobile Stable

## 本轮定位到的最重要缺陷
V46 虽修复了散热器/中冷器外围总成的爆炸滑块联动，但默认高级运行链仍然很深：V46 -> V44 cooling pack -> V42 -> V41 -> V34 -> V32 -> V25。用户此前已在 iPhone 上实际出现长期停留在“正在进入”遮罩的故障，因此移动端启动稳定性仍是阻断性交互问题。

## 本轮直接改进
新增 `versions/v47-adaptive-mobile-stable.html`。

- 移动端/粗指针设备默认不再走完整 V46 深链，而是优先进入 `v34-isolated-kinematics.html`，保留动态 16V 配气、四缸分辨进排气、喷油/燃烧及基础机械层，同时明显降低链深度和初始化等待。
- 桌面端仍默认进入 V46 完整 CAD/冷却总成版本。
- URL 参数 `?full=1` 可在移动端强制进入完整 V46 路径。
- 移动端动态核心 9.5 秒内若没有建立可渲染 `canvas3d`，自动回退到 `v25-direct.html`；回退后仍有 9 秒最终 watchdog。
- 启动判定从“高级 debug 对象全部就绪”改成“真实 canvas 已创建且有非零尺寸”，避免 QA/增强层初始化延迟继续阻塞用户看到模型。
- 启动成功后主动隐藏嵌套 boot 遮罩，并写入 `window.__v47Debug`，记录设备策略、运行链深度、是否 fallback 和启动耗时。

## 验收矩阵复盘
- 结构完整度：桌面完整路径继续使用 V46/V44/V42 的 CAD 密度、冷却包、正时/气路/飞轮/传感器等；移动默认路径为稳定性优先，结构复杂度低于桌面完整路径，因此不能判定全平台都达到基准。
- 拆解层级：桌面 V46 继续保留，且外围冷却包已修复真实 `explodeAmount` 联动；移动默认 V34 保留基础爆炸/剖视能力，但外围冷却包不加载。
- 曲柄连杆/配气相位：移动 V34 和桌面 V46 均继承 720° 四缸动力学与动态 16V 路径。
- 燃油/润滑/冷却：桌面完整；移动默认以 V34 的动态燃油/气流和基础系统为主，外围 V44 冷却包不加载。
- PBR：继承现有基础 Studio PBR/PhysicalMaterial。
- 剖视/爆炸、多视角、Hover、实时状态、压力温度、P–V、性能：现有路径保留；本轮主要修启动可靠性，不声称新增视觉基准超越。
- 性能/交互：本轮直接降低移动端默认 iframe/初始化复杂度，解决此前 iPhone 长时间卡启动遮罩的高风险路径。
